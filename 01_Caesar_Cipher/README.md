# Task 01 — Caesar Cipher

## Overview

This project implements the Caesar Cipher encryption technique using Python.

The Caesar Cipher is a substitution cipher in which each alphabetic character is shifted by a fixed number of positions within the alphabet.

This implementation supports both encryption and decryption while preserving spaces, numbers, punctuation, and letter casing.

---

## Objectives

- Implement the Caesar Cipher algorithm.
- Support encryption and decryption.
- Handle uppercase and lowercase characters.
- Preserve spaces, numbers, and punctuation.
- Support shift values greater than the alphabet size.
- Validate invalid user input.
- Perform manual and automated testing.
